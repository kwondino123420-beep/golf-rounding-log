# 라운딩 로그 (Golf Rounding Log) — MVP

라운딩을 다니면서 겪는 3가지 문제를 해결하기 위한 웹앱입니다.

1. **골프장/코스별 홀 파(par) 인지 어려움** → 코스를 한 번 등록해두면 라운드마다 각 홀의 파를 자동으로 안내합니다.
2. **이번 홀에 몇 타를 쳐야 하는지, 목표 달성을 위해 앞으로 어떻게 쳐야 하는지 모름** → 참가자별 목표(전체 타수 또는 파 대비)를 설정하면, 매 홀 남은 홀 수 대비 권장 타수와 목표 달성 가능 여부를 실시간으로 안내합니다.
3. **스코어카드 누계 기록 불가** → 홀별 스코어를 기록하면 OUT/IN/TOTAL, 파 대비 누계가 자동 계산되고, 완료된 라운드는 기록 탭에서 참가자별 누계 리더보드(평균 타수, 평균 파 대비, 베스트 스코어)로 확인할 수 있습니다.

## 실행 방법

빌드 과정이 필요 없는 순수 정적 페이지입니다. `index.html`을 브라우저로 열거나, GitHub Pages로 바로 배포할 수 있습니다.

```
open index.html
```

또는 저장소 Settings → Pages에서 `main` 브랜치를 배포하면 별도 서버 없이 바로 서비스할 수 있습니다.

## 공유 방식 (MVP의 한계)

현재는 별도 백엔드/서버 없이 동작하는 MVP이기 때문에, "링크를 공유한 사람들끼리 실시간으로 누계를 공유"하는 기능은 **완전한 실시간 동기화가 아니라 링크 기반 스냅샷 공유** 방식으로 구현되어 있습니다.

- 라운드 화면에서 "공유 링크 만들기"를 누르면 현재까지의 라운드 데이터(코스, 참가자, 홀별 스코어)가 URL에 압축되어 담깁니다.
- 이 링크를 카카오톡 등으로 전달하면, 받은 사람이 열었을 때 자동으로 "불러오기" 안내가 뜨고, 확인을 누르면 자신의 기기(로컬 저장소)에 사본으로 저장되어 이어서 기록할 수 있습니다.
- 이후 스코어가 갱신되면 다시 공유 링크를 만들어 전달하는 방식으로 그룹 간 누계를 맞춥니다.

모든 데이터는 각자의 브라우저 `localStorage`에 저장되며, 기기를 바꾸면 데이터가 유지되지 않습니다.

## 다음 단계 (정식 서비스/앱으로 발전 시)

MVP가 잘 동작하는 것이 확인되면 아래 순서로 고도화할 수 있습니다.

1. **실시간 백엔드 도입**: Firebase/Supabase 등으로 라운드 데이터를 서버에 저장 → 링크 하나로 여러 명이 실시간으로 같은 스코어카드를 보고 갱신.
2. **계정/로그인**: 기기가 바뀌어도 내 기록 유지, 친구 목록, 반복 참가자 관리.
3. **코스 데이터베이스 공유화**: 개인별 로컬 코스 등록 대신, 전국 골프장 코스 정보를 공유 DB로 제공(홀별 파, 핸디캡 인덱스, 거리 등).
4. **네이티브 앱 전환**: PWA(홈 화면 추가, 오프라인 지원)로 먼저 전환 후, React Native 등으로 iOS/Android 앱 출시.
5. **통계/분석 강화**: 파3/4/5별 평균, 트렌드 그래프, 목표 대비 달성률 등.

## 파일 구조

- `index.html` — 앱 전체(마크업, 스타일, 로직)가 담긴 단일 파일. 빌드 도구 없이 정적 호스팅만으로 동작.
